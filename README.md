# 🚀 Exercícios de Java Swing - FBr

Repositório criado para guardar os exercícios desenvolvidos na disciplina de Linguagem de Programação III[cite: 23].

## 📌 Projetos Desenvolvidos

* **Calculadora Simples:** Realiza operações matemáticas básicas usando caixas de diálogo `JOptionPane`.
* **Conversor de Temperatura:** Converte valores entre Celsius e Fahrenheit de acordo com a escolha do utilizador[cite: 21].
* **Verificador de Idade:** Valida e informa se o utilizador é maior ou menor de idade[cite: 22].

## 🛠️ Tecnologias Utilizadas

* **Java**
* **Java Swing** (`javax.swing`)
* **VS Code** & **Git**
